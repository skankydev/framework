# 12.1 Les Fields

## Comment ça marche

Chaque type de champ (`text`, `select`, `checkbox`...) est une classe qui étend `FormField`. Elle ne fait presque rien elle-même : son boulot, c'est de pointer vers un template PHP.

```php
class TextField extends FormField {
    protected string $type     = 'text';
    protected string $viewHtml = 'fields.default';
}
```

`$viewHtml` désigne le template, en dot-notation comme une vue classique. Pour le rendu, le template reçoit toutes les propriétés du champ.

Pour trouver le fichier, le framework regarde d'abord dans les fields qu'il publie lui-même (config `view.fields`), sinon il retombe sur `view.folder`, le dossier de vues classique. Ça te permet de fournir ton propre template pour un champ livré avec le framework, en le mettant dans ton dossier de vues, sans toucher à la config.

`FormBuilder::add($name, $type, $options)` retrouve la classe du `$type` grâce à la config `class.fields`, un alias court vers la classe complète (même principe que `class.rules` et `class.middlewares`) :

```php
'class' => [
    'fields' => [
        'text'   => \SkankyDev\Form\Fields\TextField::class,
        'select' => \SkankyDev\Form\Fields\SelectField::class,
        // ...
    ],
],
```

Un type inconnu lève une exception tout de suite, plutôt que de te sortir un champ cassé sans rien dire.

### Les options communes à `add()`

```php
$this->add('title', 'text', [
    'label'           => 'Titre',           // texte du <label>, sinon $name tel quel
    'value'           => 'valeur initiale', // écrasé par old()/setData() s'ils en ont une
    'rules'           => 'required|max_length:120',
    'attributes'      => ['class' => 'form-input', 'placeholder' => '...'],
    'labelAttributes' => ['class' => 'form-label'],
    'id'              => 'CustomId',        // sinon dérivé du name
]);
```

`rules` alimente `FormBuilder::validate()` ([12.2](012.2-La-Validation.md)). Un champ sans `rules` n'est simplement jamais vérifié. Le champ expose aussi `isRequired()` (vrai si `'required'` fait partie des règles), pratique pour ajouter une classe CSS `required` sur le label sans répéter l'information.

## La liste des existants

`text`, `textarea`, `number`, `email`, `password`, `hidden`, `color`, `date`, `datetime`, `checkbox`, `radio`, `select`, `file`. Tous sont livrés par le framework et déclarés dans `class.fields`.

La plupart n'ont rien de plus que le type et le template. Deux exceptions à connaître :

- **`select`** prend `options` (des paires `valeur => libellé`) et `empty` (ajoute une option vide en tête) :
  ```php
  $this->add('status', 'select', ['options' => ['draft' => 'Brouillon', 'published' => 'Publié'], 'empty' => true]);
  ```
- **`file`** rend un `<input type="file">`. Dès qu'un form contient un champ `file`, le `FormBuilder` ajoute tout seul `enctype="multipart/form-data"` sur le `<form>`. En édition, si la valeur est un `StoredFile`, le fichier actuel est affiché au-dessus du champ (miniature pour une image). Le fichier uploadé, tu le récupères côté controller avec `$request->file('name')`, qui rend un `UploadedFile` ([05](005-La-Requete-Client.md)), pas via le form : les fichiers ne repassent jamais par `old()`, pour des raisons évidentes.

## En ajouter un

Il te faut trois choses : une classe, un enregistrement dans `class.fields`, et un template.

```php
class RatingField extends FormField {
    protected string $type     = 'rating';
    protected string $viewHtml = 'fields.rating';

    protected int $max = 5;

    public function __construct(string $name, array $options = []) {
        parent::__construct($name, $options);
        $this->max = $options['max'] ?? 5;
    }
}
```

```php
'class' => [
    'fields' => [
        'rating' => \App\Form\Fields\RatingField::class,
    ],
],
```

Toute propriété publique ou protégée du champ (`$max` ci-dessus, `$value`, `$errors`...) est automatiquement disponible dans son template. Pas besoin de préparer un tableau de variables à part.

## Sous le capot

`FormField::render()` résout le template, puis lui passe toutes les propriétés du champ avec `extract()`. C'est ce qui rend les propriétés directement utilisables par leur nom dans le template.
